# Project 180: Cheeku Companion Robot

## Overview
Project 180 is a bilingual smart pet rabbit companion robot built with a distributed hybrid architecture.

## Core Stack
- ESP32 NodeMCU for Wi-Fi control, motor driving, and sensor polling
- L298N H-bridge for dual DC tracked motors
- 4x VL53L0X ToF sensors for all-side obstacle detection
- Smartphone as FPV camera and wake-word trigger hub
- Laptop Python server for cloud + offline AI failover
- Second phone as manual remote controller

## Key Behaviors
- Stop the motors immediately if any ToF sensor detects an obstacle under the safety threshold
- Keep the local control loop independent of cloud connectivity
- Fall back from Gemini to local Ollama when needed
